Benny's Cocktails

Welcome to Benny's Cocktails

A cocktail recipe book for personal use or bar staff. Recipes are stored in a GitHub Gist — a free file hosting service — so they're backed up and accessible on any device.

What you'll need

A free GitHub account and a personal access token with Gist permissions.

First-time setup

  1. Create a free account at github.com if you don't have one.
  2. Go to gist.github.com and create a new Gist. Set the filename to recipes.json and the content to []. Set it to Secret, then click Create secret gist.
  3. Copy the long ID from the URL — that's your Gist ID.
  4. Go to github.com/settings/tokens, click Generate new token → Classic. Tick only the gist checkbox. Copy the token.
  5. In this app, tap the 🔑 key icon in the header, paste your Gist ID and token, then tap Save & connect.
Your credentials are saved only on this device in the browser's local storage. They are never sent anywhere other than GitHub's servers.

Setting up on a new device

Each device needs to be connected separately. Tap the 🔑 key icon and enter the same Gist ID and token.

Adding a cocktail

Tap + Add cocktail in the header. Fill in the name, tags, base spirit, technique, glass type, ice type, garnish, and standard drinks.

Ingredients and method sections

Use the + Ingredient and + Step buttons to build your recipe. New ingredient rows default to ml as the unit. If you want to group items (e.g. separate a syrup from the main cocktail), tap + Section to create a named section.

Collapsing sections while editing

Each ingredient or method section has a ⌄ chevron in its header. Tap it to collapse into a compact summary showing each ingredient's name, amount, and unit. Useful for keeping long recipes manageable.

Glass type and icons

Choose a glass type from the dropdown or type a custom name. Each glass type has an icon — visible on recipe cards and in the recipe view. You can change which icon represents each glass type in Settings → Glasses by tapping the icon.

Frozen glass

Toggle the ❄ snowflake next to the glass dropdown to mark the glass as frozen. Frozen glasses display with a blue tint.

Garnish

The garnish field is a multi-select pill input. Type to search from your managed garnish list (organised by category), or type a custom garnish and press Enter. Multiple garnishes can be added. Custom garnishes are automatically saved to your garnish library.

Ice type

Choose from common ice types (Regular, Crushed, Large Cube, Sphere, Block, Pebble, Shaved) or type a custom ice type.

Standard drinks

Enter the number of Australian standard drinks in the cocktail. This value scales with the recipe — at ½× it shows half, and at 2×+ it shows the total with a breakdown (e.g. "4.5 (3 × 1.5) std drinks").

Recipe variations

Use the Variation of dropdown at the bottom of the edit form to link a cocktail to its parent recipe. For example, set "Spicy Margarita" as a variation of "Margarita". The parent recipe automatically shows all its variants, and each variant shows a link back to the parent.

Drafts and publishing

Every new recipe starts as a Draft. The current status is shown as a badge in the edit form header. Use the Publish/Unpublish button in the edit form footer to change status. Toggle the Drafts switch in the toolbar to show or hide unpublished recipes.

Organising with tags

Tags categorise your cocktails — things like "Bourbon", "Classic", "Sour", or "Spicy". Tags are used for filtering and grouping on the main page. Manage tag categories and order in Settings → Tags.

Ticking off while making

While viewing a recipe, tap any method step or ingredient to mark it as done — it fades with a strikethrough. Tap again to un-tick. Resets when you close the recipe.

Editing and deleting

When viewing a recipe, tap the ✎ pencil icon to open the edit form. The 🗑 bin icon in the footer moves the recipe to the bin, where you can restore or permanently delete it.

Undoing changes

The ↩ ↪ undo/redo buttons in the edit form header track your changes within that editing session. Changes are not undoable once saved.

Scaling a cocktail

When viewing a recipe, use the ½× / 1× / 2× / 3× / 4× / 5× scale buttons to adjust quantities. Ingredient amounts update proportionally, with units adjusting sensibly (e.g. 750ml becomes 0.75L).

Ingredients that don't scale proportionally

Some ingredients — like bitters, salt rims, or egg whites — may need specific amounts at different scales rather than simple multiplication. Tap the ⊘ button next to any ingredient when editing to set exact amounts for each scale size. Leave a field blank to use proportional scaling for that size.

Method steps that change with scale

The same ⊘ flag works for method steps — useful when instructions differ at larger batch sizes, such as adjusting shaking technique or splitting into multiple shaker tins. If a scale override field is left blank, the original step text is shown.

Choosing which scales are available

When editing, tick or untick the individual scale checkboxes (½×, 2×, 3×, 4×, 5×) to control which scale buttons appear in the recipe view. The 1× button is always shown.

Turning off scaling entirely

The Cocktail can be scaled toggle disables scaling entirely for recipes where it doesn't apply. Scale controls won't appear in the recipe view.

Adding substitutes

Any ingredient can have one or more substitutes. When editing an ingredient, tap the ⇄ button to open the substitutes panel. Each substitute has its own name, amount, unit, and an optional Reason field (e.g. "low ABV version", "if unavailable").

Inherited fields

A substitute's amount and unit default to the parent ingredient's values (shown as placeholder text). Leave a field blank to inherit the parent's value — useful when only the spirit changes but the quantity stays the same.

Choosing a substitute when viewing

Ingredients with substitutes show a ⇄ button in the recipe view. Tapping it opens a chooser listing the original and all substitutes. Select one to swap that ingredient. Choose Original cocktail to revert.

Scaling substitutes

Substitutes support the same scale overrides as regular ingredients. Use the ⊘ button within the substitute panel to set specific amounts at different scales.

Substitute groups

Assign a Group to substitutes (e.g. "Low ABV Version", "Virgin/Mocktail", "Spicy Version"). When substitutes have groups, a Mode bar appears above the ingredients in the recipe view. Tapping a mode activates all substitutes in that group at once. Tap Original to revert all.

Searching

Use the search bar to find cocktails by name or tag. On mobile, tap the magnifying glass icon to show the search field.

Filtering

Tap Filter in the toolbar. Select tags across categories — within a category, any match counts (OR). Across categories, all must match (AND). Filters include Base Spirit, Standard Drinks ranges, Technique, and Glass type. Unselectable options are dimmed when they would return no results.

Grouping

Tap Group to organise recipes into labelled sections. Group by any tag category, Base Spirit, Glass, Technique, or Standard Drinks. A recipe matching multiple tags in the same group appears under each heading.

Downloading your cocktails

Tap the ↓ icon in the header to open the export panel. Select recipes to include, then choose a format.

Available formats

Text file (.txt) — plain text listing every recipe with ingredients, substitutes, and method steps.

Markdown (.md) — formatted with headings and bold text. Opens in any markdown viewer, Notion, or Obsidian.

Spreadsheet (.csv) — one row per recipe. Opens in Excel or Google Sheets.

Interactive HTML (.html) — a self-contained file for one recipe with scale buttons and substitute toggles. Share with anyone — just open in a browser.

Full Gist backup (.json) — complete snapshot of your Gist files (recipes, bin, settings). Use to migrate or restore.

Automatic backups

Every save also writes backup.txt and backup.csv to your Gist automatically.

Adding to your iPhone home screen

  1. Open the app in Safari (must be Safari).
  2. Tap the Share button (square with arrow up) at the bottom.
  3. Tap Add to Home Screen.
  4. Name it and tap Add. Opens full-screen from your home screen.

Connecting on a new device

Open the app, tap 🔑, enter your Gist ID and token, and tap Save & connect.

Using without internet

The app works offline from the last loaded data. You can browse, search, and edit. Changes sync automatically when you're back online. A banner indicates when you're offline.
